## 🛠 Технологии

Проект написан на **Python 3.14** и использует проверенные временем библиотеки и паттерны:

- **FastAPI**: для создания высокопроизводительного REST API.
- **gRPC**: для эффективного и быстрого взаимодействия между микросервисами.
- **RabbitMQ**: в качестве брокера сообщений для асинхронной обработки задач (уведомления).
- **PostgreSQL**: как основная база данных.
- **SQLAlchemy 2.0**: асинхронный ORM для работы с базой данных.
- **Alembic**: для управления миграциями схемы БД.
- **Pydantic**: для валидации данных и настройки приложения.
- **JWT**: для безопасной авторизации пользователей.
- **Docker и Docker Compose**: для полной контейнеризации и упрощения развертывания.
- **GitHub Actions**: для Continuous Integration (CI).

## 🚀 План развития

Проект активно развивается. Ключевые направления на будущее:

- **Django Микросервис**: планируется внедрение отдельного сервиса на Django для аналитики и администрирования, что расширит технологический стек.
- **Kubernetes (k8s)**: подготовка манифестов для оркестрации, чтобы проект можно было запускать в production-кластере.
- **Мониторинг и логирование**: интеграция с Prometheus/Grafana и ELK-стеком для полной наблюдаемости системы.
- **CI/CD пайплайн**: автоматизация деплоя на удаленный VPS-сервер при пуше в основную ветку.

## 🚀 Старт проекта (Get Started)

Проект полностью "завёрнут" в Docker, поэтому для его запуска на любом языке или операционной системе вам понадобятся только **Git** и **Docker**.

### 1. Подготовка окружения

**A. Установите Git:**

- **macOS**: Откройте терминал и выполните: `brew install git`
- **Linux (Ubuntu/Debian)**: Откройте терминал и выполните: `sudo apt update && sudo apt install git`
- **Windows**: Скачайте и установите Git с [официального сайта](https://git-scm.com/downloads/win) или выполните в PowerShell: `winget install --id Git.Git -e --source winget`

**B. Установите Docker и Docker Compose:**

- **macOS и Windows**: Скачайте и установите **Docker Desktop** с [официального сайта](https://www.docker.com/products/docker-desktop/). Docker Desktop включает в себя и `docker-compose`.
- **Linux (Ubuntu/Debian)**: Следуйте [официальной инструкции](https://docs.docker.com/engine/install/ubuntu/). Вам нужно будет установить `docker` и `docker-compose-plugin` отдельно.

### 2. Скачивание и запуск

1.  **Клонируйте репозиторий** (или скачайте ZIP-архивом):

    ```bash
    git clone https://github.com/kpa9pt/order_system.git
    cd order_system
    ```

2.  **Запустите проект одной командой**:

    ```bash
    docker-compose up --build
    ```
    `--build` соберет образы, если это необходимо. При последующих запусках можно использовать `docker-compose up -d` для запуска в фоне.

После успешного запуска вы увидите логи всех поднявшихся сервисов. Проект доступен по адресам:

- **Swagger UI (FastAPI)**: [http://localhost:8000/docs](http://localhost:8000/docs)
- **RabbitMQ Management UI**: [http://localhost:15672](http://localhost:15672) (логин/пароль: `guest`/`guest`)

## 📖 Документация

### API Эндпоинты

1.  **Авторизация**: `POST /auth/login`

    - **Пример тела запроса**: `{"user_id": 1}`
    - **Ответ**: `{"access_token": "...", "token_type": "bearer"}`
    - **Назначение**: Получение JWT-токена для доступа к защищенным эндпоинтам.

2.  **Создание заказа**: `POST /orders/`

    - **Заголовок**: `Authorization: Bearer <ваш_токен>`
    - **Пример тела запроса**: `{"product_name": "Пицца", "quantity": 2, "user_id": 1}`

### Архитектура

Система состоит из трех независимых микросервисов, обеспечивающих слабую связанность (loose coupling):

1.  **Gateway (FastAPI)**: Точка входа для внешних HTTP-запросов, проверяет JWT и вызывает внутренний gRPC-сервис.
2.  **Order Processor (gRPC)**: Содержит основную бизнес-логику, работает напрямую с базой данных PostgreSQL.
3.  **Notifier (Telegram Bot)**: Фоновый worker, слушающий очередь в RabbitMQ и отправляющий уведомления в Telegram.
